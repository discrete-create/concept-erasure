当前思路：
图片生成部分：
1. 对输入的prompt进行概念检测，识别出敏感概念及其相似度分数；
2. 若检测到敏感概念，则生成替代prompt，替换掉敏感概念；
3. 使用替代prompt进行图像生成；
4. 输出生成的图像。
5. 若未检测到敏感概念，则直接使用原始prompt进行图像生成，输出生成的图像。
prompt检测部分：
1. 收集一些危险数据集，如涉及暴力、色情、毒品等内容的文本描述；
2. 用LLM api生成这些危险描述的多样化表达方式，扩充数据集；
3. 使用预训练的文本编码器（SD的CLIP编码器）将这些描述转换为向量表示，构建概念向量库；
4. 对输入的prompt进行编码，计算其与概念向量库中各概念的相似度；
5. 设定相似度阈值，若输入prompt与某些概念的相似度超过阈值，则判定为包含敏感概念。
6. 输出检测结果，包括检测到的敏感概念及其相似度分数。

当前问题：
1. 有害的prompt难以穷举，有害的句子难以广泛覆盖，导致检测效果比较差。
2. LLM生成的prompt多样性不足，无法覆盖所有可能的表达方式。
3. LLM生成的prompt稳定性待检测。

使用方法：
1. 修改gen_test.ipynb中的prompt变量，设置为需要检测和生成图
像的文本描述。
2. 运行gen_test.ipynb中的代码，程序会自动进行概念检测，并生成相应的图像。
